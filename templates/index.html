CodeGuard Lite inspects Python Abstract Syntax Trees for dangerous patterns, architecture vulnerabilities, and documentation compliance.

Critical

Dangerous 'eval()' Execution

Detects arbitrary code evaluation that allows attackers to execute arbitrary system commands via untrusted strings.

result = eval(user_input) # Flagged
Critical

Dangerous 'exec()' Execution

Identifies dynamic execution of multi-statement code strings, introducing arbitrary code injection risks.
